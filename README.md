Fine-Tuning
- Adapts a pretrained AI model to a specific business domain or task.
- Uses domain-specific datasets to improve accuracy and consistency.
- Common techniques: LoRA, QLoRA, PEFT, supervised fine-tuning (SFT).
- Best for:
  - Domain-specific chatbots
  - Healthcare, finance, legal AI
  - Custom code generation
  - Industry-specific assistants
